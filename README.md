
# Bincom ICT Python Interview Test
This project contains Python solutions to the Bincom ICT programming assessment.

## Questions Solved

1. Mean of colours
2. Most frequently worn colour (Mode)
3. Median of colours
4. Variance
5. Probability of selecting red
6. Saving colour frequencies to PostgreSQL
7. Recursive searching algorithm
8. Random binary number generation and conversion to decimal
9. Sum of the first 50 Fibonacci numbers

## Technologies Used
- Python 3
- PostgreSQL
- psycopg2
- Python Statistics Module

## Database
The project uses PostgreSQL to store colour frequencies.

Update the database credentials in the Python file before running the database function.

## Data Cleaning
The spelling error BLEW was corrected to BLUE.
ARSH was retained pending clarification.
